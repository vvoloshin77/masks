# Проект для обработки банковских операций
## Цель проекта
Интерактивная консольная программа для анализа и фильтрации банковских операций. Позволяет загружать данные из различных форматов файлов (JSON, CSV, XLSX), фильтровать операции по статусу, дате, валюте и другим параметрам, а также выполнять поиск по ключевым словам с использованием регулярных выражений.
## Установка
Требуется Python 3.10 или выше
1. Клонировать репозиторий: git clone
   Перейти в папку проекта: cd APP
2. Создание виртуального окружения: python -m venv venv
   Активация окружения Windows: venv\Scripts\activate
3. Установить зависимости (если потребуется): poetry install (openpyxl, re, pandas)
## Основные возможности
1. Загрузка данных из JSON, CSV и XLSX файлов
2. Фильтрация операций по статусу (EXECUTED, CANCELED, PENDING)
3. Сортировка по дате (возрастание/убывание)
4. Фильтрация по валюте (рублевые транзакции)
5. Поиск по ключевому слову в описании с использованием регулярных выражений
6. Категоризация операций по типам
7. Маскирование чувствительных данных (номера карт и счётов)
8. Полная типизация кода для работы с mypy
9. Интерактивное меню с валидацией ввода пользователя## Использование
## Использование
1. filter_by_state - Функция фильтрует список операций по статусу state
2. sort_by_date - Функция возврвщвет отсортированный по дате список
3. mask_account_card - Функция маскиирует номер карты и счета
4. get_date - Функция принимает строку, возвращает дату в стандартном формате
5. filter_by_currency - Функция поочередно возвращает транзакции
6. transaction_description - Функция принимает список, возвращает описание транзакций
7. card_number_generator - Функция генерации номера банковских карт в формате: ХХХХ ХХХХ ХХХХ ХХХХ
8. transactions_csv_to_dict - Функция читает данные из файла формата .csv
9. transactions_excel_to_dict - Функция читает данные из файла формата .xlsx
